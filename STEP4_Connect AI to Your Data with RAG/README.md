# LangChain: From Zero to Hero 🚀

## Learning Path with Todd (Senior AI Engineer)

This project is your journey from zero to hero with LangChain framework.

### Prerequisites
- Python 3.13+
- Basic understanding of Python
- API key for OpenAI (or other LLM provider)

### Installation

```bash
# Install dependencies
pip install -e .

# Or using uv (faster)
uv pip install -e .
```

### Environment Setup

Create a `.env` file in the project root:
```
OPENAI_API_KEY=your_api_key_here
```

### Learning Modules

1. **Lesson 1**: Basic LLM Usage - Simple prompts and responses
2. **Lesson 2**: Prompt Templates - Reusable prompt structures
3. **Lesson 3**: Chains - Composing multiple operations
4. **Lesson 4**: Memory - Conversation context management
5. **Lesson 5**: RAG Basics - Document loading and retrieval
6. **Lesson 6**: Vector Stores - Embeddings and similarity search
7. **Lesson 7**: Production Patterns - Error handling, logging, monitoring
